# How it works
- The web scraper scrapes the Natural History Museum's pages for dinosaur facts. The facts are saved to a JSON file. 
- The quiz generator builds five random questions from predefined templates. The questions are passed to the Bottle app and displayed on a styled HTML page.
- The user can select their answers, submit the quiz, and receive their score on the results page.
- Pressing the "Play Again" button will redirect the user to the quiz page with a fresh set of questions.


All dinosaur information credits go to the [Natural History Museum](https://www.nhm.ac.uk)
